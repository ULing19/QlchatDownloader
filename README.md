# 千聊下载器

独立 Windows 桌面程序，将账号可正常访问的千聊课程保存到本机。支持视频 MP4、音频 M4A、图文 HTML、内置浏览器登录、订单授权、课程分类和批量下载。

项目仓库：[github.com/ULing19/QlchatDownloader](https://github.com/ULing19/QlchatDownloader)；当前 Release：[v0.4.1](https://github.com/ULing19/QlchatDownloader/releases/tag/v0.4.1)。

直接下载：[安装版](https://github.com/ULing19/QlchatDownloader/releases/download/v0.4.1/QlchatDownloader-0.4.1-x64-Setup.exe) · [绿色版](https://github.com/ULing19/QlchatDownloader/releases/download/v0.4.1/QlchatDownloader-0.4.1-x64-Portable.exe)

0.4.1 修复自动同步后的章节折叠状态，并按视频、音频、图文分别显示数量。手机号登录的临时会话通过系统加密保存在本机，重启可恢复；缓存最长保留 7 天，服务端仍可使会话提前失效。千聊返回“没有媒体文件”时明确说明原因。

## 0.4.0 自动整理全部学习内容

登录千聊后，下载器会自动读取账号的已购专栏和最近学习，展开专栏目录，按课程名称和章节分类，并默认勾选全部课时。也可以在“我的学习”页点击“读取全部课时”重新整理。

视频保存为 MP4，音频保存为 M4A，图文保存为本地 HTML；课程媒体类型来自千聊目录字段。重复课时按课程 ID 合并，某个专栏暂时读取失败会显示在结果中，其他课程仍可继续批量下载。

## 0.3.1 批量下载修复

修复目录中标为 `normal`、`ppt` 的视频课被静默漏掉的问题。目录读取后会默认全选所有可下载视频课，并显示音频或图文课的暂不支持数量。每节课下载失败时会刷新播放地址并自动重试，完成后才进入下一节。

## 0.3.0 我的学习

支持 [千聊“我的学习”页面](https://h5.qlchat.com/wechat/page/mine/study)。点击“同步学习列表”会分别读取“我的课程”和“最近学习”的全部分页，合并重复条目并保留两种来源标记。可按来源筛选、搜索课程并读取目录。同步完成后列表保存在本机，重新启动仍可查看；任一来源读取失败时保留上一次完整列表。训练营、共读等特殊类型保留显示并标注暂不支持。

已用登录账号验证：我的课程 8 门、最近学习 100 条，最近学习共读取 11 页。列表中的音频课、直播中课程等仍可能没有可下载视频；课程可列出不表示所有类型都能下载。

## 0.2.2 授权保存修复

修复 Windows 应用容器将文件重定向到其他磁盘时，激活后保存授权报 `EXDEV` 的问题。写入临时文件后确认其真实物理目录，再在同目录完成原子替换；重命名失败时保留原文件并清理临时文件。课程库和保存位置也采用相同方式保存。升级保留千聊登录会话、设备标识和本机数据。

## 安装使用

1. 运行 `QlchatDownloader-0.4.1-x64-Setup.exe`，选择安装位置；也可直接运行 `QlchatDownloader-0.4.1-x64-Portable.exe`。
2. 打开登录窗口，用购课账号完成登录。下载器和外部网页使用各自的登录会话。
3. 登录后等待自动整理课程，默认全选已识别的课时。也可点击“同步学习列表”后“读取全部课时”重新整理，或直接粘贴单节/整套课程链接。点击“下载全部课程内容”开始保存；网络或签名地址短暂失败时会自动刷新并重试。
4. 输入闲鱼订单号完成本机授权（订单号本身就是兑换码，不需要另填兑换码），选择保存文件夹，开始下载。可查看进度、取消任务和打开保存位置。

账号登录状态只保存在本机，此程序使用独立的应用数据目录，与钉钉及小鹅通下载器分开。学习列表按当前登录账号从平台同步，本机课程库记录已读取过目录的课程。切换账号或购买新课程后请重新同步；平台学习数据可能延迟更新。无需将 Cookie、验证码或密码发送给其他人。

每节课程下载前会重新获取播放地址，避免长队列中签名过期。再次下载时，已通过本地完整性检查的课时会自动跳过，未完成的临时文件会清理后继续。日志不显示签名地址和登录凭据。同名文件会另行命名，不覆盖已有视频。

## 订单授权

闲鱼商品：[千聊课程下载器](https://www.goofish.com/item?id=1093753190581)。订单号就是兑换码，只需填写一次；钉钉商品的订单不能激活千聊。

授权服务使用现有 HTTPS 订单授权接口，千聊产品在服务端使用独立分区。用户只需输入原始闲鱼订单号，例如 `123456789012`，订单号本身就是兑换码。这使千聊订单与钉钉订单分开计数；每个订单最多绑定两台设备。订单授权缓存保存在本机，服务临时不可用时沿用短期离线租约。GitHub 发布包不包含订单号、兑换码或管理密钥。

## 支持范围

- 千聊普通视频课程的正常授权播放地址，输出 MP4。
- 仅处理当前账号有权访问的课程；未购课、失效课程、直播中内容或特殊播放器可能无法下载。
- 课时列在目录中并不保证千聊仍保留媒体文件；平台返回“没有媒体文件”的课时会明确失败，其他课时继续处理。
- 不支持 Widevine 等 DRM 课程。平台更新可能需要更新解析逻辑。
- 内置浏览器可能无法播放部分视频，下载结果以下载完成后的文件检查为准。

## 源码运行和打包

需要 Node.js，以及 Electron 41.2.0、electron-builder 26.8.1。脚本优先使用本项目依赖；当前工作区也可复用相邻 `小鹅通下载器/node_modules` 的运行时，无需重复下载。

```powershell
npm start
npm test
npm run build:win
```

`tools/build-win.ps1 -CheckOnly` 可只检查构建依赖。默认生成 Windows x64 安装版和绿色版，安装包位于 `dist`。FFmpeg 二进制因超过 GitHub 普通 Git 对象大小限制而作为 Release 资源单独提供；源码构建前从同一版本的 GitHub Release 下载 `ffmpeg.exe` 到 `assets/ffmpeg.exe`。安装版和绿色版已将 FFmpeg 独立打包。

## 第三方组件

本程序通过独立的 FFmpeg 进程处理媒体。随包携带的是 [Gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 的 FFmpeg 9.0 essentials Windows x64 静态构建，启用了 `--enable-gpl --enable-version3`，按 GPLv3 分发。程序没有修改该 FFmpeg 二进制文件。

完整许可证、实际构建参数和二进制 SHA-256 分别随安装包保存在 `resources/COPYING.GPLv3.txt`、`resources/FFMPEG-BUILD.txt` 和 `resources/THIRD_PARTY_NOTICES.txt`。FFmpeg 保持独立文件，可用兼容版本替换。

- [FFmpeg 许可说明](https://ffmpeg.org/legal.html)
- [FFmpeg 9.0 上游源码压缩包](https://ffmpeg.org/releases/ffmpeg-9.0.tar.xz)
- [FFmpeg 9.0 上游源码树](https://github.com/FFmpeg/FFmpeg/tree/n9.0)
- [Gyan 构建存档与源码参考](https://github.com/GyanD/codexffmpeg/releases)

FFmpeg 静态构建还包含第三方库，相关版本及构建来源可在 Gyan 对应构建包的 README 和源码参考中查阅。
